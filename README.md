# Reminder App

A mobile reminder app built with [Expo](https://expo.dev). Schedule personalized notifications throughout your day, stay on top of your tasks, and get a fun surprise every time you tap a notification.

---

## Features

- Create reminders with a custom label and time range (between 8 AM and 11 PM)
- Schedule 1 or more notifications per reminder — for example, get notified 3 times a day to do the dishes
- Edit or delete any reminder at any time
- Cancel scheduled notifications without deleting the reminder
- Tap a notification to be taken to a fun video 🎉

---

## Getting Started

**1. Install dependencies**

```bash
npm install
```

**2. Start the app**

```bash
npx expo start
```

From there you can open the app in:

- [Expo Go](https://expo.dev/go) — quickest way to try it on your phone
- [Android emulator](https://docs.expo.dev/workflow/android-studio-emulator/)
- [iOS simulator](https://docs.expo.dev/workflow/ios-simulator/)
- [Development build](https://docs.expo.dev/develop/development-builds/introduction/)
